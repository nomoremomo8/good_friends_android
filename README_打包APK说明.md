# Good Friends 旅行记账管家 Android 稳定版项目包

此包使用固定版本 Capacitor 5.7.8，避免 latest 造成 Node/Java 版本冲突。

## 使用步骤
1. 删除旧仓库中的全部文件。
2. 解压本 zip，将所有内容上传到仓库根目录。
3. 进入 Actions → Build Android APK → Run workflow。
4. 构建成功后下载 Artifact：GoodFriends-debug-apk。
5. 解压得到 app-debug.apk，发到安卓手机安装。

## 数据说明
APK 不内置涠洲岛真实数据。请用单独的 JSON 备份文件在 App 内导入。
